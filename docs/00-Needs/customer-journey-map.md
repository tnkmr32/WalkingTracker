# カスタマージャーニーマップ

## ペルソナ

| 項目 | 内容 |
|------|------|
| 年齢 | 20代 |
| 特徴 | 冒険や非日常に憧れているが、山・海など非日常の場所に積極的に行かない（行けない）人 |
| 状況 | 現代的な都市生活の中に閉じ込められており、日常の中に新鮮さ・意味を求めている |
| テクノロジー | スマートフォンを使いこなしている |
| 根本的な欲求 | 「自分の毎日が特別であってほしい」という感覚 |

---

## コアコンセプト：スケールの置き換え

### 参照体験
「月まであと〇〇km」のような宇宙スケールアプリが生み出す体験：
- 日常の歩行という小さな行為が、宇宙という巨大なスケールとリンクする
- 「自分の歩く行為が宇宙に届いている」という感覚が、歩くことを特別にする

### このアプリが目指すこと
**宇宙** を **歴史・文化・自然** に置き換え、同じ「スケールの驚き」を日常に届ける。

| 軸 | 体験のイメージ |
|----|---------------|
| 歴史 | 「あなたの今月の歩行距離は、坂本龍馬が脱藩時に歩いた距離と同じです」 |
| 文化 | 「累計歩行距離がお遍路88か所巡りの距離を超えました」 |
| 自然 | 「今月の歩行距離は、富士山を3往復した高さに相当します」 |

**2つのスケール体験を同時に提供する：**

- **マクロ（累積距離）**：積み上げた距離が歴史・文化・自然の偉大なスケールとリンクする
- **ミクロ（現在地）**：今歩いている場所の歴史・文化・自然の文脈が明かされる

## ジャーニーマップ

### フェーズ概観

```
[認知] → [導入] → [歩中] → [歩後] → [定着・推奨]
```

---

### フェーズ 1：認知（Awareness）

**状況**
冒険家の挑戦成功ニュースや登山・旅行のSNS投稿を目にし、自分の平凡な日常と比較して虚しさを感じる瞬間。

| 項目 | 内容 |
|------|------|
| ユーザーの行動 | ニュースやSNSを眺める。何か変えたいと思うが具体的な行動に至らない |
| 思考 | 「なんか毎日同じことの繰り返しだな」「すごいな、自分とは違う世界だな」 |
| 感情 | 虚しさ、焦り、憧れと諦めが混在 |
| タッチポイント | SNS・ニュース・App Store検索 |
| 機会 | 「あなたの散歩は、すでに冒険だった」というコンセプトのキャッチコピー・スクリーンショット |

---

### フェーズ 2：導入（Onboarding）

**状況**
アプリをダウンロードし、初めて起動する。何ができるか、自分に続けられるかを試している。

| 項目 | 内容 |
|------|------|
| ユーザーの行動 | アプリを起動し、歩行の記録を開始する |
| 思考 | 「どんな情報が出てくるんだろう」「続けられるかな」 |
| 感情 | 期待、少しの不安 |
| タッチポイント | オンボーディング画面、初回の歩行記録 |
| 機会 | 初回起動直後に「現在地の歴史情報」または「あと〇〇歩で〇〇の距離に到達」を1つ提示し、スケール体験を即座に届ける |

---

### フェーズ 3：歩中（During Walk）

**状況**
通勤・散歩・買い物など普段の歩行中にアプリが動作している。

| 項目 | 内容 |
|------|------|
| ユーザーの行動 | いつも通り歩く。通知や地図を時々確認する |
| 思考 | 「この道、江戸時代の街道だったのか」「ここで昔こんな出来事があったのか」 |
| 感情 | **感慨深さ**、発見の喜び、自分とその場所との繋がりを感じる（ミクロのスケール体験） |
| タッチポイント | 軌跡の可視化マップ、現在地の歴史・文化・自然情報の通知 |
| 課題 | 近所の歴史情報がすぐ出尽くして飽きる可能性がある |
| 対策の方向性 | 歴史・文化・自然の3軸で情報を多層化し、同じ場所でも別の切り口で提供できる |

---

### フェーズ 4：歩後（After Walk）

**状況**
歩き終えて記録を振り返る。累積データが蓄積されてきた状態。

| 項目 | 内容 |
|------|------|
| ユーザーの行動 | 今日の軌跡・距離・スポットを確認する。累積距離との比較を見る |
| 思考 | 「今月は〇〇探検家の1週間分の距離を歩いた、すごい」「お遍路まであと〇〇km」 |
| 感情 | **誇り**、達成感、自己肯定感の向上（マクロのスケール体験） |
| タッチポイント | 軌跡マップの蓄積表示、歴史・文化・自然スケールとの距離比較 |
| 課題 | 歩かない日が続くと地図の空白が目立ち、見るのが辛くなる |
| 対策の方向性 | 空白期間を「未踏の地」として前向きに表現する。比較対象まで「あと〇〇km」という前向きな指標を前面に出す |

---

### フェーズ 5：定着・推奨（Retention & Advocacy）

**状況**
散歩・通勤が「ただの移動」から「自分だけの冒険記録」に変わっていた。

| 項目 | 内容 |
|------|------|
| ユーザーの行動 | 意識的に散歩に出かける。友人に話す |
| 思考 | 「自分が毎日歩いている道って、実はすごく歴史のある場所なんだよ」 |
| 感情 | **自信**、日常への愛着、自分の存在が歴史・文化・自然とリンクしている感覚 |
| タッチポイント | 蓄積された軌跡マップ、口コミ・会話 |
| 成功状態 | 「散歩が楽しくなったんだよ」と自然に話している |

---

## 提供したい体験の核心

> **「あなたが毎日歩いているその道は、すでに冒険だった」**

ユーザーが自分の存在と歴史・文化・自然をリンクさせ、日常的な歩行そのものが特別な行為だという自信を持てる状態を目指す。

「宇宙アプリ」が宇宙のスケールで人を動かすように、このアプリは**人類が積み上げてきた歴史・文化・自然のスケール**で人を動かす。

---

## 主要な設計上の留意点

| リスク | 対策の方向性 |
|--------|-------------|
| 歩かない日が続くと記録が寂しく見える | 空白を「未踏の地・次の冒険」として表現する。「あと〇〇kmで到達」という前向き指標を前面に |
| 近所の歴史情報が出尽くして飽きる | 歴史・文化・自然の3軸で同じ場所に複数の文脈を持たせる |
| 比較対象が身近に感じられない | 有名な冒険家・歴史的な旅・自然の距離など、多様な比較対象を用意する |

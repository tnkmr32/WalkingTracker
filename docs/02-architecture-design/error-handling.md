参照：[基本設計](./basic-design.md)

## エラー種別と対応

| エラー種別 | 検出タイミング | 対応方針 |
|-----------|--------------|---------|
| GPS 権限なし | 記録開始時 | PermissionScreen へ誘導。記録は開始しない |
| GPS 権限が記録中に剥奪された（指摘#13対応） | 記録中（原則：次回のアプリ起動／サービス再起動時。プロセスが生存する稀なケースのみ即座） | 実機検証（[verification-results-20260922_163720.md](../99-others/poc/verification-results-20260922_163720.md) 課題3）で、位置情報権限をフォアグラウンドサービス稼働中に「設定」から剥奪するとOSがアプリのプロセスごと強制終了することを確認済み。この場合、ForegroundServiceもWLK001（同一プロセス）も即座に終了するため、その瞬間にアプリ側から通知・確定保存を行うことはできない（Androidのプロセスモデル上の制約であり回避不可）。<br>そのため検知・確定保存は[background-tracking.md](./background-tracking.md)「権限の検知手段」の経路Bを主経路とする：`START_STICKY`によるサービス再起動時、または次回のアプリ起動時の起動時クリーンアップ処理（[WLK001-recording.md](../03-basic-design/screens/WLK001-recording.md)参照）で`walk_session.finished_at IS NULL`のセッションを検出し、その時点で`ACCESS_FINE_LOCATION`が許可されていなければ「権限剥奪による中断」と判定する。`finished_at`はそのセッションに紐づく最後の`TrackPoint`の記録時刻とし、`steps`・`distance_meters`はその時点までのデータで確定保存する（強制終了時の破棄方針とは異なり、原因を権限剥奪と判定できた場合はデータを救済する。原因を権限剥奪と判定できない場合＝権限は許可されたままセッションが未確定で残っていた場合は、従来通り[未完了セッションの破棄方針](../03-basic-design/business-logic-design.md)に従いサイレント破棄する）。常駐通知はOSがプロセスを終了させた時点で消える（アプリ側での明示的な消去は不要、というより実行不可）。次回WLK001表示時にSnackbar/Dialogで「位置情報の権限が取り消されたため記録を停止しました」と「権限を再設定する」ボタン（SET001 へ遷移）を表示する。<br>なお経路A（プロセスが生存する場合のポーリング検知）も残しており、その場合のみ即座に停止・通知が可能 |
| 歩数センサー権限（`ACTIVITY_RECOGNITION`）が記録中に剥奪された（指摘#15対応） | 記録中 | GPSは引き続き機能するため記録は停止しない。歩数の更新のみ停止し、その時点の歩数で固定する（距離・GPS軌跡の記録には影響しない）。「歩数センサーの権限が取り消されたため、歩数の記録を停止しました」をSnackbar表示 |
| GPS 信号未取得 | 記録中 | 地図の現在地マーカーを非表示、「GPS信号を取得中…」を表示。記録は継続（TrackPoint は未保存） |
| 歩数センサー未対応端末 | アプリ起動時 | 歩数は 0 で記録を継続。「このデバイスは歩数センサーに対応していません」をトースト表示 |
| DB 書き込みエラー | TrackPoint / TraversedSegment 保存時 | Logcat に Error ログを出力。ユーザーへの通知なし（次の記録で再試行） |
| DB 読み込みエラー | 一覧・詳細画面の表示時 | 「データの読み込みに失敗しました。再度お試しください」を表示し、再読み込みボタンを提供 |
| ストレージ不足 | TrackPoint 保存時 | Logcat に Error ログを出力。セッションを強制終了し「ストレージの空き容量が不足しています」をトースト表示 |
| GeoJSON 読み込みエラー | アプリ起動時 | アプリをクラッシュさせず、踏破進捗画面に「ルートデータの読み込みに失敗しました」を表示。以降のTRV評価（`EvaluateTraversalUseCase`）はスキップされ、WLKの記録自体には影響しない（参照：[business-logic-design.md TRV業務フロー](../03-basic-design/business-logic-design.md)） |

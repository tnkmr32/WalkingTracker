# ライティング（文言ガイドライン）

参照：[デザインシステム](./README.md)

---

## 方針

- プロダクト UI は**日本語**。コピーは簡潔・平易・説明的（マーケティング調にしない）
- システム文言に近い、落ち着いた事実ベースの文体とする

---

## 声・人称

- ニュートラルで丁寧。命令形でも一人称でもなく、やわらかな促し（「〜しましょう」）で語りかける
- 「私」は使わない。「あなた」もほとんど使わない
- 励ましは空状態・端状態にのみ置く

| 場面 | 文言 |
|---|---|
| 履歴が空 | まだ記録がありません。最初の一歩を記録しましょう |
| 踏破 0% | まだ踏破済みの区間がありません。歩いて記録を始めましょう |
| 踏破 100% | 旧街道を完全踏破しました！ |

---

## 表記・記号

- ラベルは全角の日本語（`記録` / `踏破` / `履歴`）
- アクションボタンは「〜する」で終わる動詞句（「記録を開始する」「記録を停止する」「権限を許可する」）
- 日付は `yyyy/MM/dd（E）` 形式 → `2026/06/27（金）`
- 統計値は `・` で連結 → `12,345 歩 ・ 8.7 km ・ 45分`
- 注意書きは `※` で始める → `※ 拒否した場合、一部機能が使用できません`
- 数字・単位（`歩` `km` `分`）は半角で日本語中にそのまま並べる

---

## トーン

- 静か・事実ベース・控えめに動機づける
- 感嘆符（！）は完遂の祝福にのみ使う。それ以外はすべて言い切りの平叙文とする

---

## 絵文字・アイコン

- 絵文字は使用しない
- UI の意味づけには Material Symbols アイコンを使う（[icons.md](./icons.md)）

---

## 数値表示

- リアルタイム表示（歩数・距離・経過時間）はタブラー数字を用い、幅を固定する（[typography.md](./typography.md)）
- 経過時間は `HH:MM:SS` 形式

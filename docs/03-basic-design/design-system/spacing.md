# スペーシング・レイアウトグリッド

参照：[デザインシステム](./README.md)

---

## 方針

- **4dp グリッド**を基本単位とする（Material3 準拠）。すべての余白・間隔は 4dp の倍数で表現する
- 余白は直値ではなくスペーシングトークン経由で参照し、画面間で一貫させる

---

## スペーシングスケール

| トークン | 値 | 主な用途 |
|---|---|---|
| `space-1` | 4dp | ヘアライン間隔、アイコン↔ラベル |
| `space-2` | 8dp | 標準の要素間ギャップ |
| `space-3` | 12dp | カード内余白（コンパクト時） |
| `space-4` | 16dp | 画面端マージン、カード内余白 |
| `space-5` | 20dp | — |
| `space-6` | 24dp | セクション間 |
| `space-7` | 28dp | — |
| `space-8` | 32dp | 大きなセクション区切り |
| `space-10` | 40dp | — |
| `space-12` | 48dp | 最小タッチ行 |
| `space-14` | 56dp | アプリバー／背高ボタン |
| `space-16` | 64dp | — |

---

## セマンティックスペーシング

| エイリアス | 値 | 用途 |
|---|---|---|
| `screen-margin` | 16dp | 画面の左右端マージン |
| `card-padding` | 16dp | カード内側の余白 |
| `content-gap` | 8dp | 隣接要素の標準ギャップ |
| `section-gap` | 24dp | セクション間の余白 |

---

## コンポーネント寸法

| 項目 | 値 | 備考 |
|---|---|---|
| 最小タッチターゲット | 48dp | Material の最小ヒット領域 |
| ボトムナビ高さ | 80dp | M3 NavigationBar |
| TopAppBar 高さ | 64dp | M3 small TopAppBar |
| ボタン高さ（標準） | 40dp | M3 ボタンコンテナ |
| ボタン高さ（背高） | 56dp | 全幅のプライマリアクション |
| ナビアイコン | 24dp | — |
| ボタン内アイコン | 18dp | — |
| ラベル内アイコン | 16dp | 統計ラベル等 |

---

## レイアウト原則

- 記録・踏破・履歴の3画面は下部にボトムナビ（80dp）を固定し、その上をコンテンツ領域とする
- 地図画面ではコントロールパネルを画面端から 12dp 内側に浮かせてオーバーレイする
- リスト項目間は 8〜12dp、画面端は 16dp を基準とする

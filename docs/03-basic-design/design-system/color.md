## 方針

### 固定カラースキーム

ダイナミックカラーは**使用しない**。

ユーザーの壁紙に依存して配色が変わると UI の再現性がなくなり、デザインレビューや品質担保が困難になるため、静的カラースキームを常に適用する。`Theme.kt` では `dynamicColor = false` を固定する。

### テーマ：国土地理院 2万5千分の1 地形図

配色は **国土地理院の2万5千分の1 地形図** をイメージした固有の色彩系から導出する。

| 地形図の要素 | 地図上の色 | UIへの転用ロール |
|---|---|---|
| 等高線 | 茶色（`#A07040`系） | Primary |
| 植生・森林 | 薄緑（`#90C090`系） | Secondary |
| 河川・湖沼 | 水色（`#70B8D8`系） | Tertiary |
| 地図用紙 | クリーム（`#F8F4EA`系） | Background / Surface |
| 国道 | 赤（`#CC3333`系） | Error / 現在地 |

## 地図固有カラー

OSMDroid の地図上に描画する要素は Material3 のロールに依存しない固定色を使用する。  
地形図の記号色に準拠し、地図タイル上でも違和感なく視認できるよう選定する。

| 要素 | カラー | 地形図との対応 |
|------|--------|---------------|
| 現在セッション軌跡 | `#CC3333` | 国道の赤（最も目立つ経路色） |
| 過去セッション軌跡 | `#9E9E9E` | 廃線・旧道の薄灰 |
| 踏破済み区間 | `#4A7A50` | 植生の緑（歩いた土地＝踏み固めた草地） |
| 未踏破区間 | `#D8D0C0` | 未分類道路の薄茶灰 |
| 現在地マーカー | `#CC3333` | 国道の赤（軌跡と統一） |

## 使用ルール

- カラーは必ず `MaterialTheme.colorScheme.*` 経由で参照する（ハードコード禁止）
- 地図描画専用カラーのみ定数として `Color.kt` に定義してよい
- `Color.kt` の既存 `Purple40 / PurpleGrey40 / Pink40` 系は実装時に上記固定色へ置き換える
- ダークモードは未対応（将来対応時は等高線の茶を明度調整して流用する）

# モーション

参照：[デザインシステム](./README.md)

---

## 方針

- モーションは**抑制的かつ機能的**に。状態変化や進捗を伝えるためだけに用いる
- 装飾目的のバウンスや無限ループのアニメーションは使わない
- Material3 の標準イージングに準拠する

---

## イージング・デュレーション

| 対象 | デュレーション | イージング |
|---|---|---|
| プログレスバーの幅変化 | 約 400ms | `cubic-bezier(.2, 0, 0, 1)`（M3 emphasized） |
| ローディングスピナー回転 | 900ms / 周 | linear（等速） |
| ボトムナビのアクティブピル | 約 200ms | standard |
| ボタンの状態・色変化 | 約 200ms | standard（クロスフェード） |
| ダイアログのスクリム表示 | 約 200ms | standard |

---

## 個別ルール

- **記録中の軌跡**：新しい座標が加わるたびにポリラインを延伸する。点の打ち直しではなく追記で表現する
- **GPS 取得中**：スピナー＋「GPS信号を取得中…」を表示し、取得完了で現在地マーカーに切り替える
- **記録ボタン**：開始/停止で色・アイコン・ラベルを同時にクロスフェードする
- **遷移**：履歴→詳細などの画面遷移は標準のフォワード/バック遷移に従う

---

## アクセシビリティ

- `prefers-reduced-motion` 指定時は、装飾的な動きを抑え、最終状態を即時表示する

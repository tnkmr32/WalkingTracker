# インタラクション状態

参照：[デザインシステム](./README.md)

---

## 方針

- タッチアプリのため、基本フィードバックは Material の **ステートレイヤー**（ロール色を重ねる半透明オーバーレイ）とリップルとする
- 状態は色・影・形のいずれかで明示し、テキストの有無だけで状態を表さない

---

## ステートレイヤー

操作対象の前面に、その要素のロール色を以下の不透明度で重ねる。

| 状態 | 不透明度 | 補足 |
|---|---|---|
| Enabled（通常） | 0% | レイヤーなし |
| Hover | 8% | ポインタ環境のみ |
| Focus | 12% | キーボード/アクセシビリティ操作 |
| Pressed | 12% | リップルと併用 |
| Dragged | 16% | ドラッグ中 |

---

## コンポーネント別の状態

| コンポーネント | 押下時の挙動 |
|---|---|
| FilledButton | ステートレイヤー＋影をわずかに持ち上げる |
| OutlinedButton / TextButton | ステートレイヤーのみ（影なし） |
| DualStateButton | 状態で色そのものを切替（記録前＝Primary 茶 / 記録中＝Error 赤） |
| SessionCard | ステートレイヤー＋エレベーション1→2 |
| Chip | 選択で Secondary Container 塗り＋チェックアイコン表示 |
| BottomNavigationTab | 選択でアクティブピル（Secondary Container）と塗りアイコンに切替 |

---

## 無効（Disabled）状態

- 不透明度 **38%** に落とす（テキスト・アイコン・コンテナ共通）
- 影は付けない
- ポインタは `not-allowed`、操作は無効化する

---

## フォーカス可視性

- フォーカス時はステートレイヤー（12%）で可視化する
- 最小タッチターゲットは 48dp を確保する（[spacing.md](./spacing.md)）

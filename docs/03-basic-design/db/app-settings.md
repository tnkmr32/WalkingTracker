# テーブル定義：app_settings

参照：[テーブル一覧](./table-list.md)

---

## テーブル概要

| 項目 | 内容 |
|------|------|
| 物理テーブル名 | `app_settings` |
| エンティティクラス名 | `AppSettings` |
| 概要 | アプリ全体の設定を管理するシングルトンテーブル。常に `id = 1` の1行のみ存在する |
| 関連業務 | SET（アプリ設定） |

---

## カラム定義

| カラム名 | Room 型 | SQLite 型 | PK | NOT NULL | デフォルト | 説明 |
|---------|---------|-----------|----|---------|-----------|----|
| `id` | `Long` | `INTEGER` | ✓ | ✓ | `1`（固定） | レコードID。常に `1` |
| `is_onboarding_completed` | `Boolean` | `INTEGER` | | ✓ | `0`（false） | 初回起動フロー（パーミッション説明）の完了フラグ |

---

## 制約

| 制約種別 | 対象カラム | 内容 |
|---------|-----------|------|
| PRIMARY KEY | `id` | 単一レコードの一意識別 |

---

## 運用ルール

- レコードは `id = 1` の1行のみを使用する
- アプリ初回起動時に `id = 1` のレコードをデフォルト値で INSERT する
- 以降の更新は INSERT ではなく UPDATE（`id = 1`）で行う

---

## 関連テーブル

なし

# 画面設計：パーミッションリクエスト画面

参照：[画面一覧・遷移](./overview.md) / [権限設計](../../02-architecture-design/permissions.md)

---

## 概要

| 項目 | 内容 |
|------|------|
| 画面ID | SET001 |
| クラス名 | `PermissionScreen` |
| 表示条件 | アプリ起動時に必要権限が1つでも未付与の場合 |
| 目的 | 必要な権限をユーザーに説明してシステムダイアログを呼び出す |

---

## 画面間パラメータ一覧

### 受信パラメータ

なし（アプリ起動時に権限状態を自律的に判定して表示）

### 送信パラメータ

なし（全権限付与後はパラメータなしでメイン画面へ遷移）

---

## 画面項目一覧

| 項目名 | 種別 | 取得元 |
|--------|------|--------|
| 権限説明リスト（位置情報・身体活動・通知） | テキスト（静的） | 固定文言 |
| 権限を許可するボタン | ボタン | - |
| 注意文言（拒否時の機能制限説明） | テキスト（静的） | 固定文言 |
| 設定アプリへ誘導ボタン | ボタン | 「二度と表示しない」で拒否したときのみ表示 |

## 状態と動作

| 状態 | 動作 |
|------|------|
| 全権限付与済み | 本画面をスキップしてメイン画面へ |
| 権限リクエスト後に全付与 | メイン画面へ遷移 |
| 権限リクエスト後に一部拒否 | 拒否された権限の説明を表示し再リクエストを促す |
| 「二度と表示しない」で拒否 | 端末の設定アプリへ誘導するボタンを表示 |

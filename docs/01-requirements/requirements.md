# 要件定義

## 背景・目的

現代的な都市生活の中で「日常がつまらない」と感じる20代を対象に、日常の歩行行為そのものを冒険体験へと変換するAndroidアプリ。

冒険家のニュースや他者のSNS投稿を見て「自分とは違う世界だ」と感じる虚しさをトリガーとし、**歴史・文化・自然**というスケールを通じて日常の歩行に驚きと意味をもたらす。

**提供したい体験の核心：**
> 「あなたが毎日歩いているその道は、すでに冒険だった」

ユーザーが自分の存在と歴史・文化・自然をリンクさせ、日常的な歩行そのものが特別な行為であるという自信を持てる状態を目指す。

参照：[カスタマージャーニーマップ](../00-Needs/customer-journey-map.md)

## 動作環境

| 項目 | 要件 |
|------|------|
| 対応OS | Android 13（API 33）以上 |
| 対応デバイス | スマートフォン |
| 必要なハードウェア | GPS、加速度センサー（歩数計） |

## 機能要件

### 必須機能（MVP）

#### 1. 歩数記録
- 歩行を開始・停止できる
- 歩数・歩行距離を計測する
- 記録した歩行データを端末に保存する

#### 2. 軌跡の可視化
- 歩行中のGPSルートを記録する
- 記録した歩行ルートを地図上に表示する
- 過去の全歩行記録を地図上に重ねて表示する（蓄積された冒険記録として）

#### 3. 旧街道の踏破進捗率表示
- 特定の旧街道のルートデータをアプリにバンドルする
- 自分の歩行軌跡が旧街道のルートと重なった区間を踏破済みとして記録する
- 旧街道全体に対する踏破済み区間の割合（%）を表示する
- 踏破完了まで「あと〇〇km」を表示する

### 追加機能

#### 4. 現在地コンテキスト情報
- 歩行中、現在地周辺の歴史・文化・自然に関する情報を提示する
- 新しいスポットに近づいたタイミングで通知する

#### 5. 歩行サマリー
- 日・週・月単位で歩行記録を集計して表示する

#### 6. 休息日の表現
- 歩かない日が続いても、地図の空白を「未踏の地」として前向きに表現する
- 踏破完了まで「あと〇〇km」を前面に表示し、再開を促す

## 非機能要件

| 項目 | 要件 |
|------|------|
| パフォーマンス | 歩行記録中のバックグラウンド処理が60秒以上途切れないこと |
| バッテリー消費 | 1時間の歩行記録でバッテリー消費が10%以内に収まること |
| オフライン対応 | 歩数記録・軌跡表示・踏破進捗表示はオフラインで動作すること |
| データ保存 | 歩行データは端末ローカルに保存する |
| プライバシー | 位置情報を外部サーバーへ送信しない |
| レスポンス | 地図・軌跡の描画が2秒以内に完了すること |

---

## 制約・前提条件

- バックエンドサーバーを持たないスタンドアローン構成
- データは端末内のみで管理する
- 旧街道のルートデータはアプリにバンドルする
- `ACTIVITY_RECOGNITION`・`ACCESS_FINE_LOCATION` パーミッションが必要

---

## 用語定義

| 用語 | 説明 |
|------|------|
| 軌跡 | ユーザーが歩行したGPSルートを地図上に線で表示したもの |
| 旧街道 | 江戸時代以前から続く歴史的な街道（例：東海道、中山道） |
| 踏破済み区間 | ユーザーの歩行軌跡と旧街道ルートが一致した区間 |
| 踏破進捗率 | 旧街道の全区間に対する踏破済み区間の割合（%） |
